# 简易图片编辑器 · 简介

一个基于Python，用AI辅助编程写成的桌面画图程序，基于 **PyQt5**（界面）+ **Pillow / NumPy**（图像处理），面向日常涂鸦、修图、做简单动画的需求。

## 主要功能

**绘画工具**
- 画笔、橡皮、取色、油漆桶填充、渐变、拖动
- 六种笔刷：圆头、方形、软喷枪、颗粒喷枪、颗粒笔、涂抹笔
- 可调笔刷粗细、硬度、不透明度，支持颗粒质感

**线条与形状**
- 直线 / 曲线（三次贝塞尔，可拖控制点）
- 实线、虚线、点线，可加单端或双端箭头
- 矩形、椭圆、三角形、菱形、五边形、六边形、八边形、五角星、四角弧星、心形
- 支持形状填充，Shift 约束正多边形

**选区与编辑**
- 矩形选区、椭圆选区、套索，支持叠加（Ctrl）
- 选区可整体移动、缩放、旋转
- 复制 / 剪切 / 粘贴（含系统剪贴板）、全选、反选、取消选择
- 变换：旋转 90°/180°、水平/垂直镜像
- 特效：锐化、马赛克、模糊、灰度

**图层**
- 多图层，可新建、删除、重命名、上下移动
- 显示/隐藏、不透明度、混合模式（正常、正片叠底、滤色、叠加）
- 合并可见、向下合并、合并选择
- 蒙版编辑（黑白画笔涂抹）

**多帧动画**
- 打开 GIF / TIFF / WebP 多帧图片
- 逐帧编辑、新建/删除帧、合并所有帧
- 每帧独立时长、循环次数设置
- 内置播放器，支持实时预览

**其他**
- 图片参数：亮度、对比度、饱和度、缩放
- 画布参数：改尺寸、锚点、填充色
- 标尺、像素网格
- 项目文件（`.myp`，zip 打包图层）保存/打开
- 拖拽图片文件直接导入
- 撤销 / 重做（多步历史）
- 支持 PNG / JPG / WebP / GIF / BMP / ICO 等格式导出

## 操作要点

- **左右键**：左键用前景色，右键用背景色
- **Ctrl + 滚轮**：缩放视野
- **Shift**：拖拽时约束比例 / 角度
- **Ctrl**：选区叠加
- **Esc**：提交当前线条 / 取消选区
- **Delete**：删除选区内容

## 技术特点

- 笔刷合成基于 **NumPy 向量化**，支持颗粒、软边、透明度
- 涂选用 **premultiplied alpha** 插值，不会把透明区当黑色
- 选区绘制走 **mask 累积**，一笔内同一像素只取最大覆盖度，浓度均匀
- 线条预览与最终结果**共用同一套 PIL 渲染逻辑**，所见即所得
- 图层混合、蒙版、不透明度在 `Layer.render()` 里统一处理

## 定位

适合**轻量级、单文件启动**的画图场景：随手涂鸦、给图片加标注、做简单逐帧动画、快速修图。不追求专业软件的性能与精度，胜在依赖少、代码清晰、易改易扩展。
